# پایگاه دانش دستیار

این پوشه قرارداد داده‌ای دستیار را نگه می‌دارد و باید همراه مدل‌های Django بازبینی شود.
اطلاعات حساس، کلیدها و snapshot خارج از محدودهٔ کاربر نباید در این فایل‌ها ذخیره شوند.

تفاوت‌های مهم ثبت‌شده:

- `SituationReport` و `AdjustmentSituationReport` صورت‌وضعیت هستند و مبلغ آن‌ها در
  `payment_amount_field` قرار دارد؛ `FinancialDocument` مدل جداگانهٔ سند مالی است.
- اولویت واقعی `SubProject.sub_project_number` است و مدل محدودیت صریح ۱ تا ۵ ندارد؛
  متدهای `Project` ظرفیت ۱۰ زیرپروژه را مدیریت می‌کنند.
- مقادیر enum دقیقاً همان مقادیر فارسی مدل هستند، از جمله «فرست بها» و گزینه‌های
  روش اجرای سه‌عاملی/دفترفنی استان.
