# Dynamic Django Website Deployment for Windows VPS
## Auto-configure with DNS, Database, SSL (win-acme), HTTP/HTTPS

This dynamic deployment system automatically configures your Django website on a Windows VPS with minimal user input, using win-acme for SSL certificate management.

## Features

- **Auto IP Detection**: Automatically detects server's public and local IP addresses
- **Dynamic DNS Configuration**: Prompts for domain and provides DNS setup instructions
- **Automatic Database Setup**: Creates MySQL database and user with secure credentials
- **SSL Certificate Management**: Automatic Let's Encrypt SSL certificate setup using win-acme
- **HTTP/HTTPS Support**: Configures both HTTP and HTTPS with automatic redirects
- **Service Management**: Installs and configures nginx and Django as Windows services
- **Advanced Monitoring**: Comprehensive service management and monitoring tools

## Quick Start

### 1. Prerequisites
- Windows Server 2016/2019/2022 or Windows 10/11
- Python 3.9+ installed at `C:\Python39\python.exe`
- MySQL Server installed and accessible
- Administrator privileges
- Domain name pointing to your server

### 2. One-Command Deployment
```cmd
# Run as Administrator (with win-acme)
deploy_with_winacme.bat

# Or use the original dynamic deployment
dynamic_deploy.bat
```

The script will:
1. Detect your server's IP addresses
2. Prompt for your domain name
3. Create MySQL database and user
4. Configure Django settings
5. Install and configure nginx
6. Set up Windows services
7. Configure SSL certificates
8. Start all services

## Configuration Details

### Environment Variables (.env)
The script automatically creates a `.env` file with:
```env
SECRET_KEY=<auto-generated-secure-key>
DEBUG=False
ALLOWED_HOSTS=<domain>,www.<domain>,localhost,127.0.0.1,<public-ip>

# Database Configuration
DB_ENGINE=django.db.backends.mysql
DB_NAME=project_manager_db
DB_USER=django_user
DB_PASSWORD=django_password_2024
DB_HOST=localhost
DB_PORT=3306

# Security Settings (auto-configured for HTTPS)
SESSION_COOKIE_SECURE=True
SESSION_SECURE_COOKIES=True
SESSION_CSRF_COOKIE_SECURE=True
SECURE_SSL_REDIRECT=True
```

### Database Configuration
- **Database Name**: `project_manager_db`
- **Username**: `django_user`
- **Password**: `django_password_2024` (auto-generated)
- **Character Set**: `utf8mb4`
- **Collation**: `utf8mb4_unicode_ci`

### Nginx Configuration
- **HTTP**: Port 80 (redirects to HTTPS after SSL setup)
- **HTTPS**: Port 443 (SSL/TLS with Let's Encrypt)
- **Static Files**: Served directly by nginx
- **Media Files**: Served directly by nginx
- **Rate Limiting**: Configured for login and API endpoints
- **Security Headers**: HSTS, XSS protection, content type sniffing

### SSL Certificate Management
- **Provider**: Let's Encrypt (free SSL certificates)
- **Tool**: win-acme (Windows ACME Simple)
- **Auto-renewal**: Configured via Windows Task Scheduler
- **Certificate Location**: `C:\ProgramData\win-acme\httpsacme-v02.api.letsencrypt.org`
- **Renewal Schedule**: Weekly on Sundays at 2 AM
- **Management**: Use `setup_ssl_winacme.bat` for manual operations

## Backup and Recovery

### Automatic Backup
```cmd
# Create full website backup
advanced_service_manager.bat
# Choose option 10 (Backup website)
```

### Manual Backup Commands
```cmd
# Database backup
mysqldump -u django_user -pdjango_password_2024 project_manager_db > backup.sql

# Media files backup
xcopy media backup\media\ /E /I /Q

# Configuration backup
copy .env backup\
copy nginx\conf\nginx.conf backup\
```

### Restore from Backup
```cmd
# Restore database
mysql -u django_user -pdjango_password_2024 project_manager_db < backup.sql

# Restore media files
xcopy backup\media media\ /E /I /Q /Y
```

## Troubleshooting

### Common Issues

1. **Services won't start:**
   ```cmd
   # Check service status
   sc query nginx
   sc query DjangoProjectManager
   
   # Check logs
   type nginx\logs\error.log
   type logs\django_stderr.log
   ```

2. **SSL certificate issues:**
   ```cmd
   # Check certificate status
   certbot certificates
   
   # Test SSL
   curl -I https://yourdomain.com
   ```

3. **Database connection errors:**
   ```cmd
   # Test database connection
   mysql -u django_user -pdjango_password_2024 project_manager_db
   
   # Check MySQL service
   sc query mysql
   ```

4. **DNS not resolving:**
   ```cmd
   # Test DNS resolution
   nslookup yourdomain.com
   ping yourdomain.com
   ```

### Performance Issues

1. **High CPU usage:**
   - Check nginx access logs for high traffic
   - Monitor Django application performance
   - Consider increasing server resources

2. **Slow response times:**
   - Check database query performance
   - Monitor nginx proxy settings
   - Verify SSL certificate validity

3. **Memory issues:**
   - Monitor Python process memory usage
   - Check nginx worker processes
   - Consider adjusting nginx worker connections

## Emergency Procedures

### Complete Service Restart
```cmd
sc stop DjangoProjectManager
sc stop nginx
timeout /t 5 /nobreak >nul
sc start nginx
sc start DjangoProjectManager
```

### Emergency SSL Renewal
```cmd
certbot renew --force-renewal
sc stop nginx
sc start nginx
```

### Database Emergency Recovery
```cmd
# Stop services
sc stop DjangoProjectManager

# Restore database
mysql -u django_user -pdjango_password_2024 project_manager_db < emergency_backup.sql

# Start services
sc start DjangoProjectManager
```
